# Керування трифазним безколекторним двигуном

Система керування БДКД на STM32F407 з датчиком Холла, ПІД-регулятором обертів і
керуванням з комп'ютера через USB.

Розробка — [hopeok.com.ua](https://hopeok.com.ua/)

## Про цю копію

Копія проєкту для ознайомлення. Мета — показати архітектуру рішення, стиль коду
та роботу системи.

**Алгоритм розрахунку моментів комутації не наводиться** — у обробнику переривання
від датчика Холла залишено опис того, що робить розрахунок, але без реалізації.
Призначення пристрою та умови його застосування також не розкриваються.

Решта коду наведена повністю. Роботу системи показано у відеозаписі —
див. розділ [Демонстрація](#демонстрація).

## Обладнання

| | |
|---|---|
| Мікроконтролер | STM32F407VGT, 168 МГц |
| Зворотний зв'язок | датчик Холла |
| Зв'язок з комп'ютером | USB CDC, віртуальний COM-порт |
| Керування | повністю з програми на комп'ютері |

Фізичні потенціометри в цій версії не використовуються: запуск АЦП вимкнений, а
всі робочі параметри надходять з програми налаштування.


## Технічні рішення

### Вимірювання обертів

Період між імпульсами датчика Холла вимірюється апаратно: у перериванні лише
читається лічильник таймера і одразу скидається. Занадто короткі періоди
відсіюються порогом — це захист від брязкоту контактів.

### Формування імпульсів

Моменти вмикання і вимикання записуються в чотири регістри порівняння таймера,
тому самі імпульси формуються апаратно. Ядро лише розраховує моменти на наступний
період і в головному циклі зводить їх із сигналом ШІМ.

Три параметри форми задаються з комп'ютера і діють одразу, без перепрошивки:
затримка старту, ширина імпульсу і фазовий зсув.

### ПІД-регулятор

Модуль `pid_regulator.c` не залежить від решти системи: на вхід подається період
датчика Холла, на вихід іде шпаруватість ШІМ.

- **обмеження інтегральної складової** (anti-windup) — без нього після тривалого
  розгону регулятор перевалює за уставку;
- **експоненційна фільтрація** вимірюваної частоти перед розрахунком похибки;
- **коефіцієнти змінюються на ходу** через USB, без перепрошивки — саме так вони
  й підбиралися;
- стан регулятора інкапсульований у статичній структурі, назовні лише функції.

### Критичні секції

Спільні з перериваннями змінні читаються під захистом `PRIMASK`
(`Core/Inc/critical.h`). Пара `__disable_irq()` / `__enable_irq()` тут не
годиться: вона вмикає переривання на виході беззастережно, а якщо секцію
викликано звідти, де вони вже були вимкнені, — увімкне їх передчасно.

### Обмін з комп'ютером

Команди приймаються рядком через віртуальний COM-порт:

| Команда | Що задає |
|---|---|
| `p=`, `i=`, `d=` | коефіцієнти ПІД |
| `t=` | цільова частота |
| `l=` | затримка старту, 0…300 |
| `w=` | ширина імпульсу, 0…300 |
| `s=` | фазовий зсув, 0…500 |

Телеметрія надсилається кожні 200 мс. Дробові величини передаються цілими
числами — множаться на 10 000 на боці мікроконтролера й діляться назад на боці
комп'ютера, щоб не тягнути форматування `float` у прошивку.

### Що показано на записі

У цьому огляді демонструємо оновлений інтерфейс та програмний підхід до
налаштування ШІМ-контролера для керування електродвигуном.

Головна особливість цієї версії прошивки полягає в повній відмові від фізичних
потенціометрів та енкодерів. Усі робочі параметри тепер централізовано
налаштовуються безпосередньо через графічну панель керування.

**Параметри сигналів та збереження.** У блоці керування задаються параметри
основних сигналів: затримка сигналу (у діапазоні від 0 до 300 %), ширина
імпульсів, зсув фаз. Після внесення кожного значення необхідно натиснути кнопку
Set, щоб мікроконтролер записав налаштування у пам'ять для автономної роботи.

**Цільова частота та налаштування ПІД-регулятора.** Нижче виставляється цільова
частота — для демонстраційного тесту встановлено 150 Гц. Далі налаштовуються
коефіцієнти ПІД-регулятора: пропорційний Kp, інтегральний Ki, диференціальний Kd.
Кожне нове значення коефіцієнта також фіксується кнопкою Set.

**Моніторинг та діагностика.** Праворуч розташований графік реального часу.
Блакитна лінія відповідає заданій цільовій частоті (150 Гц), синя — фактичній
частоті з датчика Холла, а біла крива відображає поточну шпаруватість (коефіцієнт
заповнення). Масштаби за осями значень та часу можна гнучко коригувати.

У вкладці «Діагностика» відображаються точні цифрові показники поточної частоти,
розрахована шпаруватість у відсотках та активні параметри сигналів.

**Тест роботи алгоритму на осцилографі.** На осцилограмі чітко видно формування
силових імпульсів.

- Коли поточна частота вища за задану, ПІД-регулятор утримує мінімальну
  шпаруватість на рівні близько 7 %.
- У разі падіння частоти нижче 150 Гц алгоритм починає пропорційно нарощувати
  шпаруватість аж до максимальних 95 %, компенсуючи навантаження.
- При відновленні та перевищенні заданих обертів шпаруватість плавно знижується
  до вихідного рівня.

Контролер надійно відпрацьовує зворотний зв'язок і забезпечує стабільну підтримку
заданої частоти.
